## How to Restore & Continue Working
1. Download and install the matching version of **Eclipse Capella**.
2. Download `ToyCatapult_Backup_2026-11-26.zip` from this repository.
3. Open Eclipse Capella and go to **File -> Import... -> General -> Existing Projects into Workspace**.
4. Select **Select archive file**, browse to `ToyCatapult_Backup_2026-11-26.zip`, ensure `ToyCatapult` is checked, and click **Finish**.
